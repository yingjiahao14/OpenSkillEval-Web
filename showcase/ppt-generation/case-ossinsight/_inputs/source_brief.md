## About OSSInsight

OSSInsight is a free, real-time analytics platform that tracks over **10.6 billion GitHub events**. It provides deep insights into open-source repositories, developers, and organizations — covering stars, commits, pull requests, issues, contributors, and community health metrics. The platform ranks trending repositories using a composite **Total Score = Stars score + Forks score + Base score**.
