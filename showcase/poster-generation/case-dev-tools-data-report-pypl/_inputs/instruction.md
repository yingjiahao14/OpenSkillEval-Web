## Poster Brief: PYPL Programming Language Popularity Index — April 2026

You're creating a portrait data-report poster that gives developers and tech decision-makers a clear, at-a-glance understanding of which programming languages are rising and falling in 2026. The core narrative is simple: **Python dominates, C/C++ is surging, and Java is in steep decline.** The poster should feel like a polished, modern infographic — the kind a developer would screenshot and share on social media.

### Key Priorities

- **The Top 10 rankings table is the centerpiece.** It should be the largest, most prominent element — readers need to scan the hierarchy instantly. Use clear rank numbers, share percentages, and directional trend indicators (arrows or color-coded change values).
- **The three headline metrics — Python (36.21%), C/C++ (13.21%), Java (10.01%) — should be visually dominant** near the top, styled as bold stat callouts so the power dynamics are obvious before anyone reads the table.
- **Gainers vs. losers contrast matters.** Use green/red or equivalent accent colors to make positive and negative trends pop at a glance throughout the poster.

### Visual & Style Guidance

Aim for a **dark-mode, developer-aesthetic** feel — think deep navy or charcoal backgrounds with vibrant accent colors (electric blue, bright green for gains, warm red/orange for losses). Typography should be clean and monospaced or semi-monospaced for data elements, paired with a modern sans-serif for headings. Keep whitespace generous; avoid clutter. The tone is authoritative and data-forward — no playful illustrations, just sharp data visualization and clean hierarchy.

The methodology note and emerging languages section should be present but visually secondary — smaller type, lower placement.
