## Dominant Leader: hermes-agent

NousResearch's **hermes-agent** claimed the number-one spot with **+9,715 stars** in a single week — nearly double the second-place entry. The repository provides an open-source agent framework built on the Hermes model family, and its explosive growth signals strong developer demand for fully open agent tooling that can rival proprietary alternatives.

## The Claude Code Ecosystem Surge

Five of the top 20 repositories are directly related to Anthropic's Claude Code product:

- **claude-code-best-practice** (#9, +2,151) — curated best-practice guides
- **everything-claude-code** (#10, +1,978) — comprehensive resource collection
- **claude-mem** (#11, +1,828) — memory management plugin
- **claw-code** (#15, +1,285) — alternative CLI wrapper
- **openclaw** (#16, +1,268) — open-source Claude Code extension framework

Together these five repos accumulated over **8,500 stars**, underscoring how quickly a third-party ecosystem is forming around Claude Code.

## Other Notable Trends

- **AI-assisted design** is gaining traction: VoltAgent's awesome-design-md (#5, +3,246) curates design resources in Markdown, while graphify (#7, +2,763) converts data into visual graphs using AI.
- **Microsoft's markitdown** (#6, +3,048) continues its steady climb, converting documents to Markdown for LLM ingestion — a utility play that benefits the entire AI stack.
- **New entry gstack** (#20, +1,012) by Garry Tan debuted on the leaderboard, focusing on a full-stack AI development toolkit.

## Key Takeaways

1. **Agent-first development is surging** — hermes-agent's nearly 10k weekly stars dwarf every other entry.
2. **Claude Code's ecosystem is expanding fast** — 25% of the top 20 repos orbit a single product.
3. **Utility and infrastructure tools** like markitdown show that foundational open-source packages continue to attract sustained interest alongside flashier agent projects.
