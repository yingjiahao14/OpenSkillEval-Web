# State of Developer Ecosystem 2024: Language Wars & Rising Stars

Based on responses from **23,262 developers worldwide**, the JetBrains State of Developer Ecosystem 2024 report reveals key shifts in programming languages, databases, cloud platforms, and AI adoption.

## Top Programming Languages (2017–2024)

JavaScript remains the most-used language but its dominance is eroding, while Python and TypeScript continue their multi-year ascent.

| Language | 2017 | 2019 | 2021 | 2023 | 2024 | Trend |
|---|---|---|---|---|---|---|
| JavaScript | 65% | 69% | 69% | 61% | 61% | Plateau |
| Python | 32% | 49% | 52% | 54% | 57% | Steady rise |
| HTML/CSS | 60% | 61% | 60% | 52% | 51% | Gradual decline |
| SQL | 42% | 56% | 54% | 52% | 48% | Slight decline |
| Java | 47% | 50% | 49% | 49% | 46% | Gradual decline |
| TypeScript | 12% | 25% | 29% | 34% | 37% | Strong rise |
| Rust | — | 6% | 8% | 7% | 8% | All-time high |
| Go | 17% | 20% | 23% | 18% | 17% | Stable |

Python, which started at 32% in 2017 (nearly on par with PHP at 30%), is now used by more than half of the world's programmers.

## Rising Stars & the JetBrains Language Promise Index

JetBrains introduced a new **Language Promise Index** combining five-year audience growth, growth stability, intent to adopt, and user retention. The top-ranked languages signal where the ecosystem is heading.

| Rank | Language | Promise Index Score |
|---|---|---|
| 1 | TypeScript | 199 |
| 2 | Rust | 198 |
| 3 | Python | 151 |
| 4 | Go | 129 |
| 5 | Lua | 118 |
| 6 | C++ | 113 |
| 7 | Kotlin | 113 |

Go and Rust are the languages most respondents plan to adopt, both prized for performance and concurrency. One in six Go users is considering switching to Rust. TypeScript's adoption surged from 12% in 2017 to 37% in 2024, yet JavaScript is not going anywhere — the two coexist rather than compete.

## Databases: PostgreSQL's Surge

Open-source databases dominate. PostgreSQL has seen the most dramatic growth, climbing from 32% in 2019 to 45% in 2024, narrowing the gap with long-time leader MySQL.

| Database | 2019 | 2022 | 2024 |
|---|---|---|---|
| MySQL | 60% | 52% | 52% |
| PostgreSQL | 32% | 38% | 45% |
| MongoDB | 30% | 27% | 30% |
| SQLite | 29% | 27% | 30% |
| Redis | 22% | 18% | 20% |

## Cloud & Platforms: Where Code Runs

AWS leads cloud adoption at 46%, though its share has dipped from 51% in 2022. Azure (17%) and Google Cloud (11%) are slowly gaining ground.

Desktop development (53% of developers) still surpasses mobile (30%), challenging the assumption that mobile dominates. Browser platforms lead at 58%, and server/cloud infrastructure is used by 56% of developers.

## AI Integration Is Accelerating

**18% of developers** now build integrations with AI, signaling that AI is steadily infiltrating production software. Python is the dominant language for AI/ML, with 31% of Python developers involved in AI work. Notably, 11% of C++ developers also report active AI/ML involvement — a surprisingly high figure for a systems language. Fear of AI among developers appears to be diminishing year over year.

Docker adoption is strong: **49% of developers use Docker locally**, and containerization continues to be a standard part of modern development workflows.
