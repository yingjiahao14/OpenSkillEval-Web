Strategic Recommendations

  • Prioritize quality over deeper discounting: Discount-to-rating correlation is only -0.155, so large markdowns are weak levers for satisfaction lift.
  • Use targeted promotions for visibility, not blanket cuts: Discount-to-engagement correlation is 0.012; use selective discounting in categories with low median engagement.
  • Rebalance assortment toward high-rated categories: Replicate assortment and merchandising patterns from top-rated categories; review underperforming categories in the bottom-rating table for SKU rationalization.
  • Price by segment response: Rating by price segment shows where premium pricing is tolerated versus where value pricing is necessary; use segment table to set guardrails.
  • Fix recurring CX pain points in reviews: Negative themes (charging, slow, charger, only, bluetooth) should map to listing-quality, packaging, and product-quality improvement sprints.
