Recommendation: Focus promotional efforts on 40-60% discount ranges rather than deeper discounts to protect margin while maintaining customer satisfaction.

Categories like Electronics and Home&Kitchen show below-average ratings (4.08★ and 4.04★ respectively). Recommendation: Conduct root cause analysis on these categories. Consider supplier quality audits or assortment rationalization.

3. Leverage High-Performing Categories

Top categories demonstrate that quality products with moderate discounts (40-50%) achieve the highest satisfaction. Recommendation: Use OfficeProducts as a benchmark category for supplier quality standards. Apply learnings to improve underperforming segments.
