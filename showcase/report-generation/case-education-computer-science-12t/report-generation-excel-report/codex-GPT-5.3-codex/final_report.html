Interpretation

  • The overall structure is balanced between MCQs (45.87%) and Short questions (44.95%), with Long questions consistently smaller (9.17%).
  • Baseline yearly averages are MCQs 15.0, Short 14.7, Long 3.0; most years stay near these baselines, indicating broad structural stability.
  • Notable shifts are localized (e.g., 2017 expansion, then later stabilization), rather than a continuous long-term drift.

Recurring Topics & Question Content Patterns

Observed recurring concepts

  • Programming fundamentals recur heavily: program, statement, operator, syntax, variable, switch.
  • C-language and formatting cues are frequent: printf, format specifier, void main, include stdio.
  • Database topics persist strongly: table, primary key, foreign key, relational, dbms, form/report.

Keyword counts are frequency signals from cleaned text (lowercased, `$` delimiter normalized, common stopwords removed). They indicate recurrence, not curriculum weight by marks.

Strategic Insights for Exam Preparation

  • Maintain dual-track preparation: since MCQ and Short shares are nearly equal overall, teaching plans should allocate near-equal practice time to objective recall and concise written responses.
  • Protect long-question readiness: long questions are fewer but persistent (avg 3/year), so students need weekly extended-response practice rather than last-minute drills.
  • Anchor instruction around recurring cores: emphasize programming constructs and DBMS key concepts first, then layer lower-frequency topics.
  • Use stable post-2021 volume for pacing: with 33 questions consistently from 2021–2025, mock papers can be standardized to this volume for realistic rehearsal.
  • Design mixed-format revision sets: combine MCQ + short + one long question per topic cluster (e.g., C syntax + control structures + keys/relations) to mirror historical composition.

Conclusions & Limitations

  • The exam pattern appears largely stable in composition, with one clear expansion period around 2017 and a steady structure in recent years.
  • The strongest recurring content centers on programming basics and database fundamentals, suggesting durable core emphasis in past papers.
  • Data limitations: 2020 is missing; annual vs supplementary papers are not explicitly labeled; question text may contain community transcription noise.
  • All values in this report are computed directly from data.csv; where continuity is ambiguous (e.g., missing 2020), interpretation is explicitly qualified.
