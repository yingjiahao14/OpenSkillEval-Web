Key Insights & Recommendations

Critical Findings

1. Stable Activity Levels (2015–2025): Average daily steps fluctuated within a narrow band of 10,003–11,105 across all years. No significant upward or downward trend is evident, suggesting consistent but plateaued user engagement.
2. December Peak Activity: Monthly data shows December (11,113 avg steps) and March (10,976 avg steps) as the highest-activity months, while January (10,176 avg steps) shows the lowest. This suggests year-end motivation followed by early-year fatigue.
3. Weekday vs. Weekend Gap: Tuesday shows peak weekday activity (10,799 steps) while Thursday is lowest (10,317 steps). Weekend days (Saturday: 10,537, Sunday: 10,445) fall below weekday averages. Mid-week motivation boosters could improve Thursday engagement.
4. Stress-Mood Correlation: Users reporting "Tired" mood show slightly higher stress (5.58) and slightly lower sleep (6.95 hrs) compared to "Happy" users (5.33 stress, 7.02 hrs sleep). This 0.25-point stress differential is actionable for wellness interventions.
5. Running vs. Walking Efficiency: Running yields the highest average steps (10,721) and calories (622.0), while Walking yields the lowest (10,354 steps, 607.9 cal). Encouraging walking users toward higher-intensity workouts could increase calorie burn.
