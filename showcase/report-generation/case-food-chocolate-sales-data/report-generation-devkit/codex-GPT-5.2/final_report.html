What leadership should notice

  • Monthly and quarterly charts show where 2024 accelerated or softened vs 2023.
  • Discounting occurs in 37.55% of orders, with only four discount levels present (0%, 10%, 15%, 20%).
  • Margin stability across discount levels suggests cost scales with revenue in this dataset; validate whether this matches real-world promo economics.
Important: This benchmark provides a single fact table (`data.csv`) with transaction-level sales fields and only ID keys for products, stores, and customers. The dataset documentation references additional dimension tables (products/stores/customers/calendar), but those files are not included here; therefore category/brand/cocoa%, geographic/store-type, and demographic/loyalty analyses cannot be computed from the provided data.
