Methodology & Data Controls
Metrics are computed exclusively from /app/benchmark/data.csv. No external estimates were used. Returns are based on adjusted close levels from the provided file. Annualized volatility uses daily close-to-close returns scaled by √252. Drawdown is measured as percentage decline from running peak close. Dividend totals are raw per-share sums from the Dividends column. If a metric cannot be reliably derived from the dataset, it is marked as N/A.
