Methodology & Data Boundaries

  • Primary source: /app/benchmark/data.csv; no external financial values were introduced.
  • Return basis: price return uses first and last adjusted Close values in the relevant period.
  • CAGR: (ending close / starting close)^(1 / elapsed years) - 1, using calendar-day elapsed years.
  • Volatility: standard deviation of daily percentage close returns multiplied by √252.
  • Drawdown: daily close divided by prior running peak close minus one; recovery occurs when close returns to or exceeds the prior peak.
  • Dividends and splits: event rows are summed or listed exactly as recorded in the CSV.
