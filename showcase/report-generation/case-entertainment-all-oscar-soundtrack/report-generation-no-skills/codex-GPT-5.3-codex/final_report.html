Dataset Overview & Historical Context

This dataset covers every Best Original Score winner from 1934 through 2026, totaling ceremonies. It contains unique winning composer entries and unique films.

The category itself changed names and occasionally split historically, but this file consolidates to one winner per ceremony year. This makes long-run trend analysis possible: dominance cycles, repeat-win concentration, and periods of winner diversification are directly traceable over nine decades.
