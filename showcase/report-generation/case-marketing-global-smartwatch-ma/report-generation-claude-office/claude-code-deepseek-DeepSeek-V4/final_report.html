4. Case Size & Price Premium Analysis

Quantifying the relationship between physical case size and resale price — does a larger watch face command a measurable premium?

Finding: Overall case-size/price correlation is negligible (r = 0.021) — size alone does not predict resale value. However, extremes show a pattern: 50-60mm watches command $750 median vs. $489 for sub-38mm. Mid-range sizes (38-50mm) show no consistent premium. Brand-level correlations: Apple: r=0.033 · Garmin: r=0.107 · Samsung: r=0.035.
