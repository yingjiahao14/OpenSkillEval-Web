Build commerce experiences that ship fast.

CommerceForge gives developers everything needed to build custom apps, high-performance storefronts, and AI-powered shopping agents.

CLI Setup

Install the CLI, scaffold projects, and deploy workflows with a docs-style guided setup.

npm i -g @commerceforge/cli@latest

Scaffold a full-stack app with embedded admin UI and extension points.

cf apps init --template fullstack
cf apps dev
cf apps deploy

Bootstrap and preview theme-based storefront customizations locally.

cf themes init
cf themes dev --store your-store
cf themes deploy

Start a headless project with Storefront API and typed SDK bindings.

cf storefronts init --headless
cf storefronts dev
cf storefronts publish
