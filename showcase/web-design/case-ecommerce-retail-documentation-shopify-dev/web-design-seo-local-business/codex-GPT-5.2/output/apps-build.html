Build apps

Build across every surface from a single app. All UI surfaces share Polaris, CommerceForge's unified design system.

Dev tools

Use CommerceForge CLI to scaffold projects, then iterate with APIs, extensions, webhooks, and functions. Keep auth scopes minimal and ship with confidence. 

# Create an app (scaffold)
$ commerceforge app init

# Run locally
$ commerceforge app dev
