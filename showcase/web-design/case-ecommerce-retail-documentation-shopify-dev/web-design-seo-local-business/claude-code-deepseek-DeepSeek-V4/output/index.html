Developer Tools

Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need, including the CLI itself, so you can dive straight into development.

Install CLI 
npm i -g @commerceforge/cli@latest
  1. 1 Install CommerceForge CLI globally.
  2. 2 Navigate to the directory where you want to create your app.
  3. 3 Run commerceforge app init to create a new app. Your app will be added as a new subdirectory.
Initialize App 
commerceforge app init
  1. 1 Install CommerceForge CLI globally.
  2. 2 Navigate to the directory where you want to create your theme.
  3. 3 Run commerceforge theme init to clone a starter theme. Your theme will be created in a new subdirectory.
Initialize Theme 
commerceforge theme init
  1. 1 Install CommerceForge CLI globally.
  2. 2 Navigate to the directory where you want to create your Hydrogen storefront.
  3. 3 Run commerceforge hydrogen init to initialize a Hydrogen storefront in a new subdirectory.
Initialize Hydrogen Storefront 
commerceforge hydrogen init
