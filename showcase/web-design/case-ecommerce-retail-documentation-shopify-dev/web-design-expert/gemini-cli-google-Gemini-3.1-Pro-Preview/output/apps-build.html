Build Apps

Extend CommerceForge's core functionality with apps that integrate into the admin, online store, checkout and more.

Dev Tools

Initialize new apps in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need to dive straight into development.

npm i -g @commerceforge/cli@latest
commerceforge app init
yarn global add @commerceforge/cli@latest
commerceforge app init
pnpm add -g @commerceforge/cli@latest
commerceforge app init
