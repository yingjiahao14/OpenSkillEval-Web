Dev tools

CommerceForge CLI scaffolds apps, generates extension templates, and runs local dev with secure tunneling. Pair it with a tight deploy loop and observability from day one. 

# Quick start
npm i -g @commerceforge/cli@latest
commerceforge app init

Best practices

Performance

Cache GraphQL calls where safe, batch writes, and design webhooks to be idempotent.

# Suggested webhook handler shape
POST /webhooks/orders/create
200 OK (ack fast)
queue job → process async

Security

Use least-privilege scopes, verify webhook signatures, and rotate credentials safely.

# Auth checklist
- validate HMAC
- verify timestamp
- enforce scopes
- log audit trail
