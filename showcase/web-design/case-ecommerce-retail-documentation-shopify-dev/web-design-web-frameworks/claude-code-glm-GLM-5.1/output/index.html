Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need, including the CLI itself, so you can dive straight into development.

Install CommerceForge CLI
$ npm i -g @commerceforge/cli@latest
$ yarn global add @commerceforge/cli@latest
$ pnpm add -g @commerceforge/cli@latest
Initialize your project
1
Install CommerceForge CLI globally.
2
Navigate to the directory where you want to create your app.
3
Run the command below to create a new app. Your app will be added as a new subdirectory.
$ commerceforge app init
1
Install CommerceForge CLI globally.
2
Navigate to the directory where you want to create your theme.
3
Run the command below to clone a starter theme. Your theme will be created in a new subdirectory.
$ commerceforge theme init
1
Install CommerceForge CLI globally.
2
Navigate to the directory where you want to create your Hydrogen storefront.
3
Run the command below to initialize a Hydrogen storefront in a new subdirectory.
$ commerceforge hydrogen init
