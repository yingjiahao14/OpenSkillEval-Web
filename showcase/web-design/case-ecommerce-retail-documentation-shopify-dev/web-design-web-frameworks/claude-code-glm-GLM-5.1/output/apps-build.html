Apps

Build apps for CommerceForge

Extend CommerceForge's core functionality with apps that integrate into the admin, online store, checkout and more. Build across every surface from a single app.

Build your first app App quickstart guide

Developer tools

Everything you need to build, test, and deploy your CommerceForge apps.

  • CommerceForge CLI Scaffold, serve, and deploy apps from the command line
  • Polaris design system UI components that match the CommerceForge admin
  • App Bridge Connect your app to the CommerceForge admin seamlessly
  • Development store Test your app on a free development store

App surfaces

Build across every surface from a single app. All UI surfaces share Polaris, CommerceForge's unified design system.

App Home

Build your app's main interface in the admin with Polaris web components and App Bridge.

Admin

Add actions, blocks, and print functionality to resource pages in the admin.

Checkout

Customize the checkout experience with UI extensions and backend logic.

Customer accounts

Extend order status pages and the logged-in customer experience.

Flow

Integrate triggers, actions, and templates into the automation platform.

Online store

Add dynamic functionality to merchants' storefront themes.
