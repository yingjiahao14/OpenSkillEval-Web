CLI 3.0

Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant. A single command installs all the dependencies you need, including the CLI itself, so you can dive straight into development.

  • 1Install CommerceForge CLI globally.
  • 2Navigate to the directory where you want to create your app.
  • 3Run the command below to create a new app — added as a new subdirectory.
# Install CLI globally npm i -g @commerceforge/cli@latest
# Install CLI globally yarn global add @commerceforge/cli@latest
# Install CLI globally pnpm add -g @commerceforge/cli@latest
commerceforge app init
  • 1Install CommerceForge CLI globally.
  • 2Navigate to the directory where you want to create your theme.
  • 3Run the command below to clone a starter theme in a new subdirectory.
# Install CLI globally npm i -g @commerceforge/cli@latest
# Install CLI globally yarn global add @commerceforge/cli@latest
# Install CLI globally pnpm add -g @commerceforge/cli@latest
commerceforge theme init
  • 1Install CommerceForge CLI globally.
  • 2Navigate to the directory where you want to create your Hydrogen storefront.
  • 3Run the command below to initialize a Hydrogen storefront in a new subdirectory.
# Install CLI globally npm i -g @commerceforge/cli@latest
# Install CLI globally yarn global add @commerceforge/cli@latest
# Install CLI globally pnpm add -g @commerceforge/cli@latest
commerceforge hydrogen init
