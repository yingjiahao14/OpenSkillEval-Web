Protocol

Universal Commerce Protocol (UCP)

An open standard establishing a common language for the agentic commerce ecosystem.

The Universal Commerce Protocol (UCP) is an open standard that establishes a common language and a set of primitives that allow agents, merchants, Payment Service Providers (PSPs), and Credential Providers (CPs) to communicate consistently and securely across the web. CommerceForge provides MCP tools that are UCP-compliant to build with this interoperable and extensible protocol.

Actors

Four primary actors

UCP defines interactions between four primary actors that form the agentic commerce ecosystem.

You

Agent

Platforms, agents, and applications acting on behalf of buyers.

Merchant

Sellers providing products and fulfillment.

CP

Credential Providers managing buyer identity and authentication.

PSP

Payment Service Providers handling payment processing.

Capabilities

How it works

CommerceForge provides MCP tools that implement UCP's core capabilities for agents.

Discovery

Search products across the platform, retrieve details, and help buyers find what they're looking for.

Checkout

Create checkout sessions, collect buyer information, attach payment information, and direct buyers to finish purchases on merchant storefronts.

agent-example.ts
// Initialize CommerceForge MCP client import { CommerceForgeAgent } from '@commerceforge/ucp-sdk' const agent = new CommerceForgeAgent({ apiKey: process.env.CF_API_KEY, scopes: ['catalog:read', 'checkout:write'] }) // Search the catalog const results = await agent.catalog.search({ query: 'winter jacket', filters: { priceMax: 200, inStock: true } }) // Create a checkout session const checkout = await agent.checkout.create({ variantId: results[0].variants[0].id, quantity: 1, attribution: { referrer: 'my-agent-app' } }) // Redirect buyer to complete purchase return { checkoutUrl: checkout.url }
Discovery

Product discovery via Catalog MCP

Agents can query all merchants across the CommerceForge platform, apply relevant filters, and display results buyers can interact with using the Catalog MCP server.

1

Authenticate with CommerceForge

Use OAuth 2.0 to authenticate your agent and obtain access tokens with the appropriate catalog scopes.

2

Query the Catalog MCP server

Send natural language or structured queries to search products across all merchants on the platform. Apply filters for price, availability, category, and more.

3

Retrieve variant details

Once buyers select a product, retrieve variant details (size, color, price, inventory) needed to create checkout sessions.

Checkout

Checkout flow and attribution

Coming soon — Checkout integration is in active development and will be available shortly.

As buyers select items from the Catalog, agentic apps can create and update carts and checkouts. Apps can refer buyers directly to merchant storefronts to complete checkout.

1

Create a cart

Create a cart with selected items and buyer information as the user browses and selects products.

2

Attach checkout information

Collect buyer contact information, shipping address, and attach payment credentials from a Credential Provider.

3

Direct to merchant storefront

All developers with Catalog access can direct buyers through Checkout, building referral applications and advertising models by controlling marketing attribution on top of UCP.
