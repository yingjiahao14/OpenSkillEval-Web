CLI 3.0

Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant. A single command installs all the dependencies you need, including the CLI itself, so you can dive straight into development.

  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your app.
  3. Run the command to create a new app. Your app will be added as a new subdirectory.
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your theme.
  3. Run the command to clone a starter theme. Your theme will be created in a new subdirectory.
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your Hydrogen storefront.
  3. Run the command to initialize a Hydrogen storefront in a new subdirectory.
Install
$ npm i -g @commerceforge/cli@latest
Init app
$ commerceforge app init
Install
$ yarn global add @commerceforge/cli@latest
Init app
$ commerceforge app init
Install
$ pnpm add -g @commerceforge/cli@latest
Init app
$ commerceforge app init

Requires Node.js 18+. All dependencies including CLI are installed automatically.
