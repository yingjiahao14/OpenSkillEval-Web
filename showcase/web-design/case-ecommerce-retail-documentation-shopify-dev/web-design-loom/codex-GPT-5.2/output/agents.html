Protocol overview

The Universal Commerce Protocol (UCP) is an open standard that establishes a common language and primitives so agents, merchants, Payment Service Providers (PSPs), and Credential Providers (CPs) can communicate consistently and securely across the web.

CommerceForge provides MCP tools that are UCP-compliant, giving you an interoperable foundation for discovery and checkout.

Protocol actors

UCP defines interactions between four primary actors:

Agent

Platforms, agents, and apps acting on behalf of buyers.

Merchant

Sellers providing products and fulfillment.

CP

Credential Providers managing buyer identity and authentication.

PSP

Payment Service Providers handling payment processing.

How it works

  • Discovery — search products across the platform, retrieve details, and help buyers find what they want.
  • Checkout — create checkout sessions, collect buyer information, attach payment info, and send buyers to finish checkout.

Product discovery

Agents can query all merchants across the CommerceForge platform, apply relevant filters, and display results. Once buyers select a product, your agent can retrieve variant details needed to create checkout sessions.

Pseudocode: discovery
// 1) Authenticate buyer
const buyer = await ucp.auth.login();

// 2) Search catalog
const results = await ucp.catalog.search({ query: "running shoes", filters: { priceMax: 150 } });

// 3) Fetch variant details
const variant = await ucp.catalog.variant(results.items[0].variantId);

Checkout flow

As buyers select items, agentic apps can create and update carts and checkouts. Apps can refer buyers directly to merchant storefronts to complete checkout and control marketing attribution.

Pseudocode: checkout
// 1) Create checkout
const checkout = await ucp.checkout.create({ buyerId: buyer.id });

// 2) Add items
await ucp.checkout.addLineItem(checkout.id, { variantId: variant.id, quantity: 1 });

// 3) Refer buyer to storefront checkout URL
const url = await ucp.checkout.getRedirectUrl(checkout.id, { attribution: "agent-referral" });
return url;
