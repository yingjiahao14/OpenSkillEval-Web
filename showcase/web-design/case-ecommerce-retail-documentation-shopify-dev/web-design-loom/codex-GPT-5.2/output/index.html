Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need, including the CLI itself.

Install CommerceForge CLI
npm i -g @commerceforge/cli@latest
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your app.
  3. Run the second command to create a new app (created as a subdirectory).
Initialize an app
commerceforge app init
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your theme.
  3. Run the second command to clone a starter theme (created as a subdirectory).
Initialize a theme
commerceforge theme init
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your Hydrogen storefront.
  3. Run the second command to initialize Hydrogen (created as a subdirectory).
Initialize a Hydrogen storefront
commerceforge hydrogen init
