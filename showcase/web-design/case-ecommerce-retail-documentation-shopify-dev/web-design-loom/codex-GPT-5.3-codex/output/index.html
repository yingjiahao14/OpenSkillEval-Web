CLI Setup

Install CLI tools quickly; switch package manager tabs instantly.

Install CLI and scaffold your first app extension project.

npm i -g @shopify/cli@latest

Install theme tooling and begin local theme development with fast preview cycles.

npm i -g @shopify/cli@latest && shopify theme dev

Bootstrap a Hydrogen storefront and connect to Storefront API.

npm create @shopify/hydrogen@latest
