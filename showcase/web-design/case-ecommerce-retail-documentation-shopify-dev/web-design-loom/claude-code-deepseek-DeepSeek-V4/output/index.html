Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need, including the CLI itself, so you can dive straight into development.

  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your app.
  3. Run the second command to create a new app. Your app will be added as a new subdirectory.
npm i -g @commerceforge/cli@latest yarn global add @commerceforge/cli@latest pnpm add -g @commerceforge/cli@latest
Init command: commerceforge app init

  2. Navigate to the directory where you want to create your theme.
  3. Run the second command to clone a starter theme. Your theme will be created in a new subdirectory.
npm i -g @commerceforge/cli@latest yarn global add @commerceforge/cli@latest pnpm add -g @commerceforge/cli@latest
