Protocol overview

UCP standardizes catalog retrieval, cart actions, and checkout handoff so agents can operate consistently across merchants.

How it works

1. Discovery

Agent queries merchant catalogs and normalizes product details.

2. Evaluation

Agent ranks options against shopper goals, budget, and constraints.

3. Action

Agent creates carts and initiates a secure checkout handoff.

Product discovery

Use semantic search, filters, and ranking signals to present highly relevant products with transparent rationale.

GET /ucp/products?query=trail+running+shoes&size=10&max_price=140

Checkout flow

Hand off cart context and identity signals to a hosted checkout endpoint with anti-fraud and policy checks preserved.

POST /ucp/checkout/session { "cartId": "cart_123", "agentSession": "as_456" }
