Best Practices

Follow these guidelines to build high-quality, merchant-ready apps.

Performance

Optimize API calls, minimize bundle sizes, and ensure your app loads fast for merchants worldwide.

Accessibility

Meet WCAG 2.1 standards and use Polaris components to ensure your app is usable by all merchants.

Security

Follow OAuth best practices, validate webhooks, and protect merchant data with secure coding patterns.

Compliance

Adhere to CommerceForge's Partner Program Agreement and App Store review requirements.

Localization

Support multiple languages and currencies so your app works for merchants globally.

Non-deceptive code

Ensure your app behaves as described, avoids dark patterns, and respects merchant consent at all times.
