Universal Commerce Protocol

An open standard for consistent, secure agentic commerce across the web.

What is UCP?

The UCP is an open standard that establishes a common language and a set of primitives that allow agents, merchants, PSPs, and Credential Providers to communicate consistently and securely across the web.

Protocol Actors

Four types of participants interact across the Universal Commerce Protocol to enable end-to-end agentic shopping.

Agent

How It Works

The protocol defines two primary flows that agents implement to create end-to-end shopping experiences.

Discovery

Search products across the platform, retrieve details, and help buyers find what they're looking for.

Checkout

Create checkout sessions, collect buyer information, attach payment information, and direct buyers to finish purchases on merchant storefronts.

Product Discovery

Enable agents to search the full CommerceForge catalog with rich filtering and structured results.

Catalog MCP Server

Agents can query all merchants across the CommerceForge platform, apply relevant filters, and display results buyers can interact with using the Catalog MCP server. The Catalog MCP server exposes structured product data — including titles, descriptions, pricing, availability, and images — in a format designed for agents to parse and present naturally in conversation.

Search & filter

Query by keyword, category, price range, availability, and more across the entire platform catalog.

Structured results

Retrieve complete product details, variant information, and media for rich, interactive buyer experiences.

Cart & checkout management

As buyers select items from the Catalog, agentic apps can create and update carts and checkouts. Apps can refer buyers directly to merchant storefronts to complete checkout. The protocol handles cart creation, item management, buyer identity attachment, and payment method selection — all through structured MCP tool calls.
