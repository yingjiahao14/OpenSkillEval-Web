Build Apps

Extend CommerceForge's core functionality with apps that integrate into the admin, online store, checkout, and more. Build across every surface from a single app using Polaris, CommerceForge's unified design system.

Dev Tools

CommerceForge provides a comprehensive suite of developer tools to streamline your app development workflow. From local development servers to debugging utilities, everything you need is at your fingertips.

# Install the CLI globally
npm i -g @commerceforge/cli@latest

# Create a new app
commerceforge app init

# Start the dev server
commerceforge app dev
