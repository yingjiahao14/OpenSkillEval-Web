Build apps for CommerceForge

Extend CommerceForge's core functionality with apps that integrate into the admin, online store, checkout, and more. Build across every surface from a single app.

Developer tools

CommerceForge provides a complete toolkit for app development — from local development with the CLI to testing in a sandbox environment before you submit to the App Marketplace.

  • CommerceForge CLI — Scaffold, develop, and deploy apps from the command line.
  • App Bridge — Embed your app seamlessly into the CommerceForge admin.
  • Polaris — Build consistent UIs with CommerceForge's React component library.
  • Partner Dashboard — Manage apps, payouts, and analytics in one place.

Best practices

Follow these guidelines to build high-quality, secure, and performant apps.

  • PerformanceOptimize speed across admin, checkout, storefront, and POS.
  • AccessibilityMake your app usable by everyone, including people with disabilities.
  • SecurityProtect your app and merchant data from common vulnerabilities.
  • ComplianceFollow API terms and privacy law requirements.
  • LocalizationTranslate and adapt your app for international merchants.
  • Non-deceptive codeMeet requirements for transparent and honest app behavior.
