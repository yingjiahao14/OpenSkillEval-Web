CLI Setup

Install the CommerceForge CLI and scaffold projects quickly. Package manager tabs update commands instantly.

npm i -g @commerceforge/cli@latest
cf theme init my-theme
cf theme dev
cf storefront create my-headless-store
cd my-headless-store && npm run dev
