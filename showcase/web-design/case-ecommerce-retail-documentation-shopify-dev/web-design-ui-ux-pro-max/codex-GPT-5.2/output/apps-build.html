Build apps for CommerceForge

Extend CommerceForge across admin, checkout, customer accounts, and the online store. Use the CLI to scaffold, then compose features with APIs, extensions, functions, and webhooks.

Dev tools

Use CommerceForge CLI 3.0 to initialize projects. Most teams start with commerceforge app init and then wire up GraphQL + webhooks for data and events.

Scaffold an app
commerceforge app init
Tip: Keep auth + scopes minimal until you need more.

Best practices

  • Prefer least-privilege OAuth scopes and feature-flag advanced permissions.
  • Use webhooks for event-driven processing; keep request handlers fast and resilient.
  • Design extensions for progressive disclosure: a small default UI, advanced configuration later.
  • Validate every input, especially anything that influences checkout, discounts, or payouts.
