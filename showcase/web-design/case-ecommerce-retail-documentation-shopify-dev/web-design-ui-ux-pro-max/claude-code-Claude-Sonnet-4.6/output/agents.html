Universal Commerce Protocol

An open standard for commerce agents

The Universal Commerce Protocol (UCP) is an open standard that establishes a common language and primitives allowing agents, merchants, PSPs, and Credential Providers to communicate consistently and securely across the web.

Protocol actors

You
Agent
Platforms and applications acting on behalf of buyers
