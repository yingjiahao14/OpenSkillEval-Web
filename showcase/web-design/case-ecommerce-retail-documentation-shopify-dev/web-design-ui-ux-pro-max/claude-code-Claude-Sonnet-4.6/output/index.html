CommerceForge CLI 3.0

Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant. A single command installs all the dependencies you need.

1

Install CommerceForge CLI globally using your preferred package manager.

2

Navigate to the directory where you want to create your app.

3

Run commerceforge app init to create a new app. Your app will be added as a new subdirectory.

1

Install CommerceForge CLI globally using your preferred package manager.

2

Navigate to the directory where you want to create your theme.

3

Run commerceforge theme init to clone a starter theme. Your theme will be created in a new subdirectory.

1

Install CommerceForge CLI globally using your preferred package manager.

2

Navigate to the directory where you want to create your Hydrogen storefront.

3

Run commerceforge hydrogen init to initialize a Hydrogen storefront in a new subdirectory.

Install CLI
# Install CommerceForge CLI globally npm i -g @commerceforge/cli@latest
Create app
commerceforge app init
Install CLI
# Install CommerceForge CLI globally yarn global add @commerceforge/cli@latest
Create app
commerceforge app init
