Developer tools

CommerceForge CLI, app templates, Polaris web components, and App Bridge help you scaffold, preview, and ship embedded app experiences quickly.

  • CLI workflow — Create an app, run local development, and manage app extensions from one command surface.
  • Polaris — Build consistent app UIs with CommerceForge's unified design system.
  • App Bridge — Connect embedded app screens to admin context and merchant actions.
