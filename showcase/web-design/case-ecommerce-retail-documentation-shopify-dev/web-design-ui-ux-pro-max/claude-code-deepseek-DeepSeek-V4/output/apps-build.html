Build Apps for CommerceForge

Extend CommerceForge's functionality with apps that integrate into every surface. Use our dev tools, APIs, and framework to build, test, and distribute your app to millions of merchants.

Dev Tools

Everything you need to develop, test, and ship CommerceForge apps. The CLI scaffolds projects, the App Bridge connects your app to the admin, and Polaris provides a production-ready design system.

CommerceForge CLI

Scaffold, develop, and deploy apps from the command line. Generate extensions, run local dev servers, and manage app configuration.

App Bridge

JavaScript library that connects your embedded app to the CommerceForge admin, providing navigation, toast notifications, and contextual data.

Polaris

CommerceForge's unified design system. Build consistent, accessible UIs with React components, design tokens, and Figma resources.

App Surfaces

Build across every surface from a single app. All UI surfaces share Polaris, CommerceForge's unified design system.

Best Practices

Follow these guidelines to build secure, performant, and accessible apps.

  • Performance

    Optimize speed across admin, checkout, storefront, and POS.

  • Accessibility

    Make your app usable by everyone, including people with disabilities.

  • Security

    Protect your app and merchant data from common vulnerabilities.

  • Compliance

    Follow API terms and privacy law requirements.

  • Localization

    Translate and adapt your app for international merchants.

  • Non-deceptive code

    Meet requirements for transparent and honest app behavior.
