Developer Tools

CommerceForge CLI

Initialize new apps, themes, and headless storefronts with a single command.

# Install globally
npm i -g @commerceforge/cli@latest
# Create new app
commerceforge app init

App Development Kit

Local development environment with hot reloading, mock data, and debugging tools.

# Start development server
cf app dev
# Run tests
cf app test
