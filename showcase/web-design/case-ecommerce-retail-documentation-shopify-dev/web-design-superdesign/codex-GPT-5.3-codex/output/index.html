CLI setup

Install the CommerceForge CLI, then choose what you want to build. Package-manager tabs update instantly, and each guide includes copy-ready commands.

npm i -g @commerceforge/cli@latest
forge app init
forge app dev
forge app deploy
forge theme init
forge theme dev
forge theme push
forge storefront init
forge storefront dev
forge storefront deploy
