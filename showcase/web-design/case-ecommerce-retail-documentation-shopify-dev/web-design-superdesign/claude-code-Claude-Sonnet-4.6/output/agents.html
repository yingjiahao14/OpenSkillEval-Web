Protocol Overview

Universal Commerce Protocol (UCP)

An open standard for agentic commerce interoperability.

The Universal Commerce Protocol (UCP) is an open standard that establishes a common language and a set of primitives that allow agents, merchants, Payment Service Providers (PSPs), and Credential Providers (CPs) to communicate consistently and securely across the web.

CommerceForge provides MCP tools that are UCP-compliant to build with this interoperable and extensible protocol. Any agent built on UCP can work with any UCP-compliant merchant or PSP.

Protocol Actors

The four primary actors

UCP defines interactions between four primary actors. Each plays a distinct role in the commerce transaction lifecycle.

Product Discovery

Query the CommerceForge Catalog

Agents can query all merchants across the CommerceForge platform, apply relevant filters, and display results buyers can interact with using the Catalog MCP server. Once buyers select a product, agentic apps can retrieve variant details needed to create checkout sessions.

catalog-search.ts 
import { CommerceForgeClient } from '@commerceforge/ucp-sdk';

const client = new CommerceForgeClient({
  accessToken: process.env.CF_ACCESS_TOKEN,
});

// Search the catalog across all merchants
const results = await client.catalog.search({
  query: 'wireless noise-canceling headphones',
  filters: {
    priceRange: { min: 50, max: 300 },
    inStock: true,
  },
  limit: 10,
});

// Get variant details for a specific product
const product = await client.catalog.getProduct({
  productId: results.items[0].id,
  includeVariants: true,
});
Checkout Flow

Agentic checkout

As buyers select items from the Catalog, agentic apps can create and update carts and checkouts. Apps can refer buyers directly to merchant storefronts to complete checkout.
