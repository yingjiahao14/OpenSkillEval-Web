Frequently asked questions

Common questions from developers getting started on CommerceForge.

Apps must meet CommerceForge's App Store requirements including security, performance, and UX standards. Submit your app through the Partner Dashboard and it will be reviewed within 5–7 business days. Most rejections are due to missing OAuth scopes or incomplete onboarding flows.
Managed themes use CommerceForge's fully-managed hosting with Liquid templating — ideal for Theme Store distribution. Hydrogen is a React-based headless framework for bespoke storefronts hosted on Oxygen. Choose themes for speed-to-market; choose Hydrogen for full frontend control.
The Partner Program offers revenue sharing on referrals, early access to APIs, co-marketing opportunities, and dedicated partner support. Tiers are based on the volume of merchants you serve. See the Partners Program documentation for eligibility and requirements.
For API bugs and technical issues, open a thread in the Dev Community with reproduction steps. For urgent production issues affecting merchants, use the partner support escalation path in the Partner Dashboard. Security vulnerabilities should be reported via the responsible disclosure program.
