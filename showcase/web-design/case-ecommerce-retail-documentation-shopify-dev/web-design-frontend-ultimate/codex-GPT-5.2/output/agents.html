Protocol overview

Universal Commerce Protocol (UCP)

UCP is an open standard that establishes a common language and primitives for agents, merchants, Payment Service Providers (PSPs), and Credential Providers (CPs) to communicate consistently and securely across the web.

Protocol Actors
agent
Platforms, agents, and applications acting on behalf of buyers
merchant
Sellers providing products and fulfillment
CP
Credential Providers managing buyer identity and authentication
PSP
Payment Service Providers handling payment processing
How it works

MCP tools that implement UCP primitives

CommerceForge provides MCP tools that implement UCP's core capabilities:

Discovery

Search products across the platform, retrieve details, and help buyers find what they're looking for.

Checkout

Create checkout sessions, collect buyer information, attach payment info, and direct buyers to finish purchases.

Agent loop skeleton
pseudo
// 1) Authenticate buyer (CP)
// 2) Query Catalog (Discovery)
// 3) Confirm variant + quantity
// 4) Create checkout session (PSP + merchant)
// 5) Redirect buyer for finalization + attribution
Product discovery

Search across merchants

Agents can query merchants across CommerceForge, apply relevant filters, and display results buyers can interact with using the Catalog MCP server. After selection, retrieve variant details to create checkout sessions.

Design tip

Prefer deterministic prompts: map user intent → filters → ranked results → explicit confirmation.

Checkout flow

From cart to conversion

As buyers select items, agentic apps can create and update carts and checkouts, then refer buyers directly to merchant storefronts to complete checkout. Control attribution to build referral and advertising models.
