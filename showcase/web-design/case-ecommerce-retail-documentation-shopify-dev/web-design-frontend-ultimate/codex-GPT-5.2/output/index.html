CLI Setup

Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. One command installs what you need, so you can dive straight into development.

Create, run, and distribute apps across platform surfaces.
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your app.
  3. Run the init command. Your app is created as a subdirectory.
App init
command 
commerceforge app init
Start from a starter theme and iterate with a fast preview loop.
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your theme.
  3. Run the init command to clone a starter theme into a subdirectory.
Theme init
command 
commerceforge theme init
Initialize Hydrogen storefronts with batteries included.
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your Hydrogen storefront.
  3. Run the init command to create a new Hydrogen storefront in a subdirectory.
Hydrogen init
command 
commerceforge hydrogen init
Switch tabs to update the command
Install CommerceForge CLI
global 
npm i -g @commerceforge/cli@latest

Why global install?

Keep your init workflows consistent across app, theme, and Hydrogen projects.
