Best practices

Make it feel native

  • Use Polaris patterns to match platform UI conventions across surfaces.
  • Prefer webhooks + background processing for reliable event handling.
  • Keep scopes minimal and document why each permission is required.
  • Design for failure: retries, idempotency, and observable logs.
