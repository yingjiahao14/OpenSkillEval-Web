Protocol overview

One common language for commerce agents.

The Universal Commerce Protocol (UCP) is an open standard that establishes primitives allowing agents, merchants, PSPs, and CPs to communicate consistently and securely across the web.

Protocol actors

Four actors coordinate secure purchase flows.

UCP defines the primary participants for identity, payment, fulfillment, and agent-driven buyer experiences.

agent

Platforms and apps acting on behalf of buyers.

merchant

Sellers providing products and fulfillment.

CP

Credential Providers managing buyer identity.

PSP

Payment Service Providers handling processing.

How it works

MCP tools implement UCP capabilities.

Discovery

Search products across the platform, retrieve details, and help buyers find what they're looking for.

Checkout

Create checkout sessions, collect buyer information, attach payment information, and direct buyers to finish purchases.

Product discovery

Query products across CommerceForge merchants.

Agents can query all merchants across the CommerceForge platform, apply relevant filters, and display results buyers can interact with using the Catalog MCP server. Once buyers select a product, agentic apps can retrieve variant details needed to create checkout sessions.

Checkout flow

Create carts, refer buyers, attribute outcomes.

Coming soon

As buyers select items from the Catalog, agentic apps can create and update carts and checkouts. Apps can refer buyers directly to merchant storefronts to complete checkout while controlling marketing attribution on top of UCP.
