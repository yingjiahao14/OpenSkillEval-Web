Accelerate development with CommerceForge CLI 3.0

Initialize new apps, themes, and headless storefronts in an instant with the latest CommerceForge CLI. A single command installs all the dependencies you need — dive straight into development.

  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your app.
  3. Run the init command. Your app will be added as a new subdirectory.
    Init
    commerceforge app init
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your theme.
  3. Run the init command to clone a starter theme in a new subdirectory.
    Init
    commerceforge theme init
  1. Install CommerceForge CLI globally.
  2. Navigate to the directory where you want to create your Hydrogen storefront.
  3. Run the init command to initialize a Hydrogen storefront in a new subdirectory.
    Init
    commerceforge hydrogen init
Install CLI globally
npm i -g @commerceforge/cli@latest

Tip

Prefer reproducible tooling? Pin versions in CI and run commerceforge via npm scripts.
