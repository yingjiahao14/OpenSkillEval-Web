RESTful API Access

WellStream's API platform enables real-time programmatic access to all platform data entities. Build custom applications, automate workflows, and integrate WellStream data into your internal tools with full read/write capability.

All APIs are secured with OAuth 2.0 and support rate limiting, pagination, and webhook notifications for event-driven architectures.

REST  OAuth 2.0  JSON  Webhooks

Sample Endpoints

GET/api/v1/wells
// List all wells with pagination
GET/api/v1/wells/{id}/production
// Production data for a specific well
POST/api/v1/frac/stages
// Submit frac stage completion data
GET/api/v1/land/leases
// Retrieve land lease records
GET/api/v1/assets/integrity
// Asset integrity monitoring data
