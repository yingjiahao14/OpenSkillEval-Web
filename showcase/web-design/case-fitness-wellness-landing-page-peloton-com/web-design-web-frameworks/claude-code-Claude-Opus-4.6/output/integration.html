RESTful APIs

RESTful APIs enable real-time programmatic access for custom applications and third-party integrations. WellStream's API layer supports both read and write operations, allowing your development team to build custom workflows, mobile applications, and automated processes that interact directly with your energy data.

GET /api/v2/wells — List all wells
GET /api/v2/wells/{id}/production — Production data
POST /api/v2/wells/{id}/reports — Submit daily report
GET /api/v2/land/leases — Query lease data
GET /api/v2/dashboards/{id} — Dashboard data
