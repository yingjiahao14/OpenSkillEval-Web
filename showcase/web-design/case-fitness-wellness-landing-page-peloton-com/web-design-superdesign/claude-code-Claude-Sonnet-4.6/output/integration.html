Technical Details

Explore Each Integration Method

Automated ETL Pipelines

WellStream's ETL engine orchestrates automated data movement between your energy systems and enterprise platforms—transforming raw SCADA, regulatory, and accounting data into unified schemas on a configurable schedule.

  • ✓Scheduled and event-triggered pipeline execution
  • ✓Read-only Snowflake integration for BI warehousing
  • ✓Multi-source mapping: SCADA, ERP, regulatory, accounting
  • ✓Data quality validation and transformation rules
  • ✓Full audit trail for every data movement event
  • ✓Retry logic and error handling with automated alerts
pipeline_config.json
// ETL Pipeline Configuration { "pipeline": "wellstream-to-snowflake", "schedule": "0 */6 * * *", "source": { "type": "wellstream_api", "datasets": ["production", "wells"] }, "destination": { "type": "snowflake", "schema": "energy_data", "mode": "upsert" }, "access": "read_only" }

RESTful API Access

WellStream's open REST API provides real-time programmatic access to all platform data. Build custom applications, automate workflows, and integrate WellStream into your existing tech stack with industry-standard authentication.

  • ✓RESTful JSON API with OpenAPI 3.0 specification
  • ✓OAuth 2.0 and API key authentication options
  • ✓Webhook support for real-time event notifications
  • ✓Rate limiting and quota management per tenant
  • ✓Sandbox environment for development and testing
  • ✓SDK libraries for Python, JavaScript, and .NET
api_example.py
# WellStream API — Python SDK import wellstream client = wellstream.Client( api_key="ws_live_..." ) # Fetch production data production = client.production.list( well_id="W-10042", start_date="2024-01-01", end_date="2024-12-31" ) for record in production.data: print(record.volume, record.date)
