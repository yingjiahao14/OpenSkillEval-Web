SOC Compliance

Annual Third-Party Audited Compliance

WellStream undergoes rigorous annual third-party audits to maintain SOC 1 and SOC 2 certifications—providing our clients with independently verified assurance of our security controls.

SOC 1
Service Organization Control 1
Verifies controls relevant to user entities' financial reporting. Critical for oil & gas operators where production data feeds directly into financial reporting.
  • Financial data handling controls
  • Change management processes
  • Logical access restrictions
  • Data processing integrity
  • Annual independent audit verification
SOC 2
Service Organization Control 2
Validates security, availability, processing integrity, confidentiality, and privacy of operational data. The gold standard for SaaS security assurance.
  • Security — unauthorized access prevention
  • Availability — system uptime standards
  • Processing integrity — complete and accurate processing
  • Confidentiality — data protection protocols
  • Privacy — personal information safeguards
