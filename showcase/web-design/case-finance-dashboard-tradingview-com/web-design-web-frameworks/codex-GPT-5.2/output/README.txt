ChartPulse (static build)

Open `index.html` in a browser. All pages are static and use relative links:

- `index.html`
- `chart.html`
- `markets.html`
- `ideas.html`
- `brokers.html`

Interactive elements (no build step required):

- Home: market summary tabs + ideas tabs + indicators tabs
- Chart: watchlist accordion + timeframe toggles + annual/quarterly tabs
- Ideas: popular/editors tabs + videos-only toggle
- Markets: asset-class scroll nav + mini chart timeframe/type toggles + movers session tabs
- Brokers: category filter tabs + best-rated sort
