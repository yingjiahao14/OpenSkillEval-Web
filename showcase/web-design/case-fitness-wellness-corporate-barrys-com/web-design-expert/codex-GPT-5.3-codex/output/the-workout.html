Class Breakdown

The Workout: Floor + Treadmill

Every class blends power running and focused strength to train aerobic capacity, muscular endurance, and total-body resilience.

Floor Focus

Build strength with dumbbells, kettlebells, and bodyweight movements in rotating blocks targeting major muscle groups.

Includes: Squats, presses, rows, core circuits, and mobility recovery.

Treadmill Focus

Interval-based running sequence alternating push pace, all-out efforts, and controlled recovery to improve speed and endurance.

Includes: Endurance ramps, sprint ladders, power inclines, and coached pacing.
