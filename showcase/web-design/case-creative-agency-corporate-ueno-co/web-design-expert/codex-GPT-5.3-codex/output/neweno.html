Volta Studio

The founder letter.

Our name is Volta, and all things considered, this is probably a bit of an odd website.

It's odd because there are no images. It's odd because there are no shiny videos. It's odd because there are no trendy 3D things all over the place and there is no menu and no call to action button with an icon in it. It's odd because no one writes things this long anymore and because no one has a page title called neweno.

Some things about this website are still quite normal. It uses all things all websites generally use and all things all agencies generally use too — words and punctuation and some decorative symbols. And in all honesty as much as we'd love this to be a weird website, all in all we'd still say this is still very much a pretty normal website.

In fact we had to make this website because one of those normal websites where all websites now sort of look and feel and work and maybe convert in pretty much exactly the same way was no longer making us feel anything.

We've had one of those websites before and it looked pretty good from a visual design perspective and there was nice little details in there and all those things we do and all those things made complete logical sense. But all those things and all those details just weren't us.

As all things become more and more alike and all things become less and less unique, all things lose all things and all things become all things and all things stop feeling things. We don't know exactly what this means, but then again, maybe that's sort of what this website is all about — finding feeling again and trying to make things that matter.

Now, before this starts sounding too much like one of those founder stories where someone says they always knew one day they would become this or become that, no this isn't that. This is just us saying that we care about making work that is useful and emotional, functional and memorable.

If you've made it this far, thank you for reading. If this resonates, we'd love to make something together.
