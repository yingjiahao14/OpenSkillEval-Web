Help Our Charity Do More

OpenLearnHub is a highly efficient education charity. When you donate, you help people learn new skills and provide for their families. You also help us create new resources for you to use to expand your own technology skills.

Supporter Benefits

  • No more donation prompt popups
  • You'll get a Supporter badge
  • Your profile image will get a golden halo around it
  • You'll gain access to special Supporter Discord channels — join our Discord and use the /supporter command
  • And more benefits to come soon

Current Initiatives

  • Creating new JavaScript and Python curricula
  • Creating English and math curricula
  • Translating our curriculum and tutorials into 32 languages
  • Creating a free accredited computer science bachelor's degree

Community Achievements

  • 193 full-length courses on YouTube
  • 850 text-based coding tutorials and 5 free books through OpenLearnHub Press
  • 2,455 code contributions into our open source repositories on GitHub
  • 1.5 million words translated to make our curriculum accessible in many languages

OpenLearnHub

OpenLearnHub is a donor-supported tax-exempt 501(c)(3) charitable organization. Our mission: to help people learn to code for free. We accomplish this by creating thousands of videos, articles, and interactive coding lessons — all freely available to the public.
