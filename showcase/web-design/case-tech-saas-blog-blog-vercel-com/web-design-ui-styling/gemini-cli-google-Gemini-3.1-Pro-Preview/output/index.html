Agentic Infrastructure

Every generation of software eventually demands a new generation of infrastructure. First, we configured servers by hand. Next, the cloud turned infrastructure into APIs. Then, a more important shift: infrastructure derived from the application itself. LLMs and coding agents are driving the next transition, and it's happening fast.

Agentic Growth Stats

  • 30% of deployments initiated by coding agents
  • 1000% increase from six months ago
  • 20 times more likely to call AI inference providers than human-deployed projects
  • Weekly deployments on DeployCloud have doubled in three months
  • Claude Code accounts for 75% of agent-initiated deployments, Lovable and v0 for 6%, Cursor for 1.5%

A new programming model for durable execution

The gap between prototypes and production-ready systems is huge. Code that's trivial to run locally falls apart the moment it needs to handle failures, restarts, and real traffic. Framework-defined infrastructure solved this for web applications. Workflows extends that model to long-running systems.
