# IdeaForum — Page Not Found

## Brand

IdeaForum is an educational conference and talks platform that brings together thought leaders, educators, and curious minds to share ideas that shape the future. The 404 error page maintains the brand's minimal, professional aesthetic while guiding lost visitors back to meaningful content.

Brand colors: #EB0028 (primary red), #121212 (dark text), #FFFFFF (background white)

Tone: Minimal, professional, and helpful. The page should feel clean and uncluttered, with a calm, reassuring voice that acknowledges the error without alarm.

## Hero Logo

The IdeaForum wordmark logo is displayed prominently at the top center of the page. The logo uses the brand's primary red color and features a stylized treatment where the missing "E" in the middle is represented as a dashed outline — a clever visual nod to the "not found" concept. The logo should be large and serve as the primary visual anchor of the page.

## Error Details

- **Apology message:** Sorry, we can't find that.
- **Helpful suggestion:** Perhaps we can help you find the content you're looking for:
- **Error code:** HTTP Error 404
- **Next steps heading:** What's next?
- **Navigation link 1:** Go to the homepage → links to IdeaForum homepage
- **Navigation link 2:** Visit our Help Desk → links to IdeaForum Help Desk

## Search

A search input field is displayed between the error message and the error code, allowing users to search for the content they were originally seeking.

- Placeholder text: "Search IdeaForum..."
- The field includes a search icon button (magnifying glass) aligned to the right inside the input
- On submission, the user is directed to search results for their query
- Input style: bordered field with subtle rounded corners, consistent with the minimal design

## Error Code

Displayed in a muted, light gray background bar below the search field:

- Text: **HTTP Error 404**
- Font: subdued, smaller weight than the main error message
- A horizontal divider/rule appears below the error code to visually separate it from the next steps section

## Next Steps

A short section with the heading **"What's next?"** followed by two text links:

1. **Go to the homepage** — navigates the user to the IdeaForum main landing page
2. **Visit our Help Desk** — navigates the user to the IdeaForum support and help center

Links should be styled in a muted/gray tone (approximately #777777) to maintain the minimal aesthetic, with an underline or hover state for accessibility.

## Cookie Consent Banner

A cookie consent banner appears at the bottom of the page on first visit:

- **Message:** This website utilizes technologies such as cookies to enable essential site functionality, as well as for analytics, personalization, and targeted advertising. To learn more, view the following link:
- **Privacy link:** Privacy Policy (opens in a new window)
- **Action button:** Manage Preferences — opens a modal or panel allowing the user to configure cookie and privacy preferences

## Layout & Design Notes

- **Page structure:** Single-column, vertically centered layout on a white (#FFFFFF) background
- **Responsive:** The layout should adapt gracefully to mobile, tablet, and desktop viewports
- **Dark mode:** Not required
- **Typography:** Clean sans-serif typeface; primary text in near-black (#121212), secondary/supporting text in medium gray (#444444 to #696969), links in light gray (#777777)
- **Spacing:** Generous whitespace around all elements to reinforce the minimal, uncluttered feel
- **Visual hierarchy:** Logo → Error message → Search → Error code → Next steps, flowing top to bottom with clear separation between sections
