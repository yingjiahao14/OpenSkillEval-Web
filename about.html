About OpenSkillEval

What is OpenSkillEval?

OpenSkillEval is a benchmark for evaluating how well AI agents perform on creative generation tasks — and how much specialized "skills" (tools, prompts, and workflows) improve their output quality.

Task Categories

  • Data Visualization — Generate charts and plots from structured datasets (output: PNG)
  • Poster Generation — Create informational and promotional poster graphics (output: PNG)
  • PPT Generation — Build PowerPoint slide decks from papers and data (output: PPTX)
  • Report Generation — Produce data analysis reports with embedded charts (output: HTML)
  • Web Design — Design and build multi-page websites from creative briefs (output: HTML/CSS/JS)

Evaluation Method

Each task runs inside a Docker container. The agent receives an instruction (derived from a real-world brief), optional source data, and must produce output files. An automated verifier scores the output on a 0–1 scale based on correctness, completeness, and quality criteria specific to each task type.

Skills & Variants

Skills are specialized agent configurations — custom system prompts, tool definitions, or workflow templates — that can boost performance on specific tasks. Each task category tests multiple skill variants alongside a "no-skill" baseline to measure the lift that skills provide.

Models & Agents

The benchmark tests 7 models across 4 agent platforms:

  • Claude Code — Claude Opus 4.6, Claude Sonnet 4.6, MiniMax M2.7
  • Codex — GPT-5.2, GPT-5.3 Codex
  • Gemini CLI — Gemini 3.1 Pro Preview
  • Kimi CLI — Kimi K2.6

This Site

This showcase site displays a sampled subset of the full benchmark results. The dataset includes 677 cases with 611 evaluation runs. Artifact previews (images, HTML outputs) are available for selected showcase cases.
